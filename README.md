# Meu Primeiro Git 🚀

Este é um projeto simples em Python desenvolvido para praticar os primeiros passos em programação e controle de versão utilizando o Git.

O script `programa.py` interage com o usuário no terminal, solicitando o nome e a idade atual para calcular e exibir a idade que ele terá daqui a 5 anos.

## 🛠️ Tecnologias

- **Python 3.x**

## 📋 Pré-requisitos

Para executar este programa, você precisa ter o Python 3 instalado em seu computador. Você pode verificar se o Python está instalado utilizando o comando:

```bash
python --version
```

## 🔧 Como Executar o Programa

1. Abra o seu terminal.
2. Navegue até a pasta do projeto:
   ```bash
   cd /home/mateus_batista010/meu_primeiro_git
   ```
3. Execute o script Python:
   ```bash
   python programa.py
   ```
4. Insira os dados solicitados no terminal para ver o resultado.

## 📝 Exemplo de Execução

```text
Qual é o seu nome? Mateus
Quantos anos você tem? 25
Mateus, daqui a 5 anos você terá 30 anos.
```
